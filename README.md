## 🧬 Current Research

### DensePPI-2 + 3D Structural Information

I'm currently exploring ways to improve **DensePPI-2**, a protein-protein interaction prediction approach, by incorporating **3D structural information** that is not fully represented by sequence-only inputs.

My research direction involves exploring structural information from resources such as:

- 🧬 **PDB**
- 🔬 **AlphaFold predicted structures**
- 🧠 Deep learning representations
- 🔗 Protein-protein interaction datasets
- 📐 3D protein structural features

### Research Pipeline

```text
Protein Sequence
       │
       ├──────────────► Sequence Features
       │
       ▼
3D Protein Structure
       │
       ├──────────────► Structural Features
       │
       ▼
 Feature Integration
       │
       ▼
 DensePPI-2 Improvement
       │
       ▼
 PPI Prediction
```
